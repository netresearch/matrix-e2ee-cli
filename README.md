# matrix-e2ee-cli

A command-line client for end-to-end encrypted Matrix messaging, built on [matrix-sdk](https://github.com/matrix-org/matrix-rust-sdk). It is the encryption backend of the [matrix-skill](https://github.com/netresearch/matrix-skill) agent skill and replaces its matrix-nio scripts.

Work in progress: no release yet.
